# Rocket Nozzle Concept

## Overview

This project is a converging-diverging nozzle concept inspired by aerospace propulsion applications. The model is intended to demonstrate revolved geometry, smooth transitions, and fluid-flow design relevance.

## Project Goals

- Model a clean nozzle profile using revolved features.
- Show inlet, throat, and exit geometry.
- Create a presentable render or drawing for portfolio use.
- Explain the purpose of the converging and diverging sections.

## Tools Used

- SolidWorks / CAD software
- Engineering drawing tools
- Optional: hand calculations or basic flow analysis
