# Lightweight Bracket

## Overview

This project is a lightweight structural bracket designed for mounting and mechanical support applications. The part is intended to demonstrate CAD modeling, design intent, material reduction, and engineering drawing communication.

## Project Goals

- Create a clean, manufacturable bracket model.
- Include fillets, mounting holes, and weight-reduction features.
- Show design intent through dimensions and organized geometry.
- Prepare the part for a portfolio, resume, or design review.

## Tools Used

- SolidWorks / CAD software
- Engineering drawing tools
- Optional: FEA or hand calculations
