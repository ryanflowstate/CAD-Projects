# CAD Design Portfolio

A portfolio repository for CAD models, engineering drawings, renders, and short project summaries focused on mechanical design and aerospace-relevant components.

## About

This repository highlights CAD projects involving mechanical design, structural components, fluid/propulsion-inspired geometry, and engineering communication. Each project folder includes images, drawings, CAD files, and a short writeup explaining the design intent.

## How to Use This Portfolio

For each CAD project:

1. Add a screenshot or render to the `images/` folder.
2. Add a drawing PDF to the `drawings/` folder.
3. Add CAD files such as `.SLDPRT`, `.STEP`, `.STL`, or `.OBJ` to the `cad-files/` folder.
4. Update that project’s `README.md` with a short description, tools used, and design notes.
